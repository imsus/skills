# Profile templates

Seeds for the files imsus-setup owns. Fill every `<...>` from detection or the user's answers; a topic with no answer gets one line saying so ("No release process: unpublished app."), never an empty heading. Keep each file short: a fact a command can look up (a script body, a config value) is named, not copied.

Each owned file starts with the same first line, so a re-run can tell it wrote the file:

```markdown
<!-- Written by /imsus-setup. Edit freely; re-run /imsus-setup to audit it against the repo. -->
```

## The `## Workflow` block

Goes in the rules file (`CLAUDE.md`, else `AGENTS.md`), after Matt's `## Agent skills` block when there is one. Replace an existing `## Workflow` block in place: from its heading to the next `## ` heading or the end of the file.

```markdown
## Workflow

How work is done here, set up by `/imsus-setup`. Ask `/imsus-ask` what to do next.

- **Workflows**: <feature, small change, bug, explore: the ones chosen>. See `docs/agents/workflow.md`.
- **Git flow**: <branch + PR | trunk | stacked PRs (gh-stack) | GitButler> on `<main branch>`. See `docs/agents/git.md`.
- **Harness**: <primary harness>, also <others or "none">. See `docs/agents/harness.md`.
- **Stack**: <kind, language, package manager>; verify with `<verify command>`. See `docs/agents/stack.md`.
- **CI**: <provider or "none">. See `docs/agents/ci.md`.
- **Release**: <scheme or "none">. See `docs/agents/release.md`.
- **Guardrails**: <one-line summary>. See `docs/agents/guardrails.md`.
```
